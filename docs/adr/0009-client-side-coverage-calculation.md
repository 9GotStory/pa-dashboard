# ADR-0009: คำนวณรายงาน coverage ในเบราว์เซอร์จากข้อมูลดิบ

- สถานะ: ยอมรับ · 29 ต.ค. 2569
- เกี่ยวข้อง: SPEC §10, SCHEMA §4

## บริบท

PA คำนวณค่า KPI ใน GAS แล้วส่งเฉพาะ `target`/`result` ต่อแถว ทำให้ข้อมูลรายไตรมาส/รายเดือน/รายวัคซีนหายไปตั้งแต่ฝั่ง server แต่หน้ารายงานของ Data Center ต้องสลับปี พื้นที่ ช่วงเวลา และรายการวัคซีนได้ทันที

## การตัดสินใจ

- snapshot เก็บแถวดิบของอำเภอ แยก block ต่อปี พร้อม header ของปีนั้น
- ฟังก์ชันคำนวณล้วน (`src/lib/dc/values.ts`) ตรวจ "กลุ่มคอลัมน์" จาก header (ANNUAL, รายไตรมาส 3 แบบ, รายเดือน 2 แบบ, OVERRIDE) และรวมเป้าหมาย/ผลงานก่อนคิดร้อยละ ไม่เฉลี่ยร้อยละ
- override ด้วย `col_target`/`col_result` เมื่อตารางไม่เข้ากฎ (เช่น `s_dental_0_5_cavity_free`)
- "ทั้งปี" ของตารางที่มีแต่รายไตรมาสคือผลรวม 4 ไตรมาส ซึ่งต่างจาก PA โดยตั้งใจสำหรับ KPI ที่ PA ตั้ง `effective_quarter`

## ผลที่ตามมา

- ไม่ต้องแก้ GAS ทุกครั้งที่เพิ่มรายงานชนิดเดิม การเพิ่มรายงานเป็นงานในชีต
- การคำนวณทดสอบได้ด้วย `node:test` โดยไม่ต้องมีเบราว์เซอร์หรือ GAS
- ความหมายของคอลัมน์ผลแยกย่อยที่ยังไม่รู้ (SCHEMA §4.5) รอ data dictionary ไม่ตั้งชื่อเอง

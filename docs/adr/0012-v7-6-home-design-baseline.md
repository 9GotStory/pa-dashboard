# ADR-0012: หน้าแรกเปลี่ยนแบบอ้างอิงจาก R6 เป็น V7.6 และสีของ Data Center ทั้งเว็บเปลี่ยนตาม

- สถานะ: ยอมรับ · 10 พ.ย. 2569 (D11)
- เกี่ยวข้อง: SPEC §9.1, §9.2, §9.6, GLOSSARY "R6", "V7.6", "ตำบลที่ตั้ง", ADR-0004, ADR-0011

## บริบท

Data Center สร้างตาม R6 ทั้งโครงหน้าและสี (กรมท่า/teal, SPEC §9.1) Product Owner ทำแบบหน้าแรกชุดใหม่ V7.6 (`docs/reference/v7-6/design.md` กับต้นแบบ HTML) ที่ลดกรอบ การ์ด และปุ่ม ใช้โทนเขียว และเพิ่ม Hero

ต้นแบบ V7.6 ทำโดยไม่ได้เห็นข้อมูลของระบบ จึงต่างจากของจริงหลายจุด:

- ยอดสรุปประชากรคัดลอกจากหน้าเว็บ ณ 9 พ.ย. 2569 ส่วนแท่งพีระมิดรายเพศของอำเภอและรายตำบลเป็นข้อมูลจำลอง แต่ระบบมีประชากรและอายุรายตำบลจริงจากกรมการปกครองอยู่แล้ว (ADR-0011) ช่วงอายุสุดท้ายของระบบคือ 80+ ส่วนต้นแบบใช้ 85+
- แผนที่ในต้นแบบเป็นรูปวาด ส่วนระบบใช้ขอบเขตจริงจาก MOPH GIS (ADR-0004)
- ต้นแบบมี drawer แสดงหน่วยบริการ → ตำบลที่รับผิดชอบ → หมู่บ้าน ซึ่งระบบไม่มีข้อมูล ระบบรู้เพียงตำบลที่ตั้ง
- เมนูของต้นแบบมี anchor ชี้เข้าหน้าแรก (ข้อมูลพื้นที่, โครงสร้างประชากร)

## การตัดสินใจ

- V7.6 เป็นแบบอ้างอิงด้านหน้าตาและการใช้งานของ**หน้าแรก** แทน R6
- สีและกรอบหน้า (Masthead, Footer) เปลี่ยนตาม V7.6 **ทั้งเว็บ** ส่วน `/reports` และ `/reports/{id}` ยังใช้โครงหน้าตาม R6 จนกว่าจะออกแบบใหม่ในรอบถัดไป ซึ่งรอบนั้นจะอ้างอิง design token ชุดนี้
- สีใช้ token ชื่อตามความหมายของ design.md §3.1 ขึ้นต้น `dc-` (เช่น `dc-brand-primary`, `dc-pyramid-male`) แบบ expand–contract: รอบนี้ชื่อเก่าของ R6 (`dc-blue`, `dc-navy` ฯลฯ) ชี้ไปที่ token ใหม่ที่ใกล้ที่สุด `/reports` จึงเปลี่ยนสีโดยไม่ต้องแก้ไฟล์ ส่วนหน้าแรกและกรอบหน้าใช้แต่ชื่อใหม่ ตอนออกแบบ `/reports` ใหม่จึงย้ายไปชื่อใหม่แล้วลบชื่อเก่า · ระหว่างนี้ `dc-blue` ที่เป็นสีเขียวเป็นเรื่องตั้งใจ ไม่ใช่บั๊ก
- SPEC §9.1–9.2 เป็นสัญญาของหน้าแรก design.md เป็นแบบอ้างอิงด้านหน้าตา เมื่อสองไฟล์ขัดกัน ให้ถือ SPEC
- ข้อมูลทุกตัวมาจากระบบจริง ไม่นำตัวเลขหรือข้อมูลจำลองจากต้นแบบมาใช้
- ไม่ทำ drawer เขตรับผิดชอบ หน้าแรกแสดงหน่วยบริการตามตำบลที่ตั้ง และใช้คำที่บอกว่าเป็นที่ตั้ง จะได้ไม่ถูกอ่านเป็นเขตรับผิดชอบ
- คงแผนที่ Leaflet กับขอบเขตจริงไว้ เปลี่ยนแถวปุ่มตำบลเป็น `<select>`
- คงเมนู 3 ลิงก์เดิม (หน้าแรก · คลังรายงาน · PA Dashboard) ไม่เพิ่มเมนู anchor และไม่ใช้เมนูแฮมเบอร์เกอร์

## ทางเลือกที่ไม่เลือก

- เปลี่ยนสีเฉพาะหน้าแรก: เว็บจะมีสองโทน และหัวหน้าเว็บจะคนละโทนกับเนื้อหาหน้าแรก
- ทำทุกหน้าในรอบเดียว: `/reports` ยังไม่มีต้นแบบให้ยึด
- ทำ drawer เขตรับผิดชอบด้วยข้อมูลจำลองที่ติดป้ายไว้: เป็นการเผยแพร่ข้อมูลที่ไม่จริงบนเว็บสาธารณะ ซึ่ง design.md เองก็ห้าม

# ADR-0019: PA ใช้กรอบหน้าและโทนสีของ Data Center โดยตัวเลขและพฤติกรรมคงเดิม

- สถานะ: ยอมรับ · 23 พ.ย. 2569 (D18, grill 23 พ.ย. 2569) · แทนข้อ "หน้าตาที่ `/pa` เหมือนเดิม" ของ SPEC §11 เฉพาะกรอบหน้า สี และ transition และข้อ "ไฟล์ PA เดิมห้ามแก้" ของ CODING_STANDARDS §1 เฉพาะ class ตามข้อตัดสินใจ
- เกี่ยวข้อง: SPEC §9.1, §9.6, §11, CODING_STANDARDS §1, GLOSSARY "PA", "ผู้ชม", ADR-0003, ADR-0012, ADR-0017, ADR-0018

## บริบท

PA กับ Data Center ดูเป็นคนละเว็บ สำรวจเว็บจริงเมื่อ 23 พ.ย. 2569: Data Center ใช้โทนเขียวของ V7.6 แบบแบนไม่มีเงา ส่วน PA ใช้ emerald, indigo และ rose มีเงา และไม่มี Masthead ผู้ชมที่กดเมนู "PA Dashboard" จึงไม่มีลิงก์กลับ Data Center

SPEC §11 และ CODING_STANDARDS §1 ห้ามเปลี่ยนหน้าตาและห้ามแก้ไฟล์ของ PA มาตั้งแต่เฟส 1 เพื่อกันตัวเลขที่ คปสอ.สอง ใช้ประเมินเปลี่ยนโดยไม่ตั้งใจ Product Owner ต้องการยกระดับหน้าตาของ PA ไปพร้อมกับ Data Center

PA ใช้สีผ่าน token ของ `globals.css` (`brand-*`, `neutral-*`, `accent-*` และสีสถานะ) 178 จุด และสีสำเร็จรูป `slate-*` ของ Tailwind 110 จุด มี `transition-all` 7 จุดในสามไฟล์ LCP ของ `/pa` บนเว็บจริงอยู่ที่ 2387 ms จากงบ 2500 ms (#338)

## การตัดสินใจ

- `/pa` และ `/pa/{ปี}` อยู่ใต้ Masthead และ Footer ของ Data Center
- สีของ PA เปลี่ยนเป็นโทนของ Data Center ผ่านค่า token ใน `globals.css` · สีที่บอกผ่านเกณฑ์ (เขียว) และไม่ผ่านเกณฑ์ (แดง) คงความหมายเดิม
- ในไฟล์ component ของ PA แก้ได้เฉพาะ class ของสีและ transition · markup, state, การคำนวณ และข้อความห้ามแก้เหมือนเดิม · เงาของการ์ด มุมโค้ง ป้ายอังกฤษ และการจัดวางจึงคงเดิม
- ตัวเลขที่ `/pa` แสดงต้องเหมือน production: `pa:compare` ได้ "PA unchanged" ทุก ticket
- PA ไม่ใช้ Motion (ADR-0018) และทุก ticket ที่แตะ `/pa` วัด LCP ของ `/pa`
- ทำหลังงานของ Data Center

## ทางเลือกที่ไม่เลือก

- **PA คงเดิมทั้งหมด:** ไม่เสี่ยง แต่ผู้ชมยังเห็นสองเว็บ และ PA ไม่มีทางกลับ Data Center
- **ใส่ Masthead กับ Footer อย่างเดียว:** มีทางกลับ แต่สีใต้กรอบยังเป็นอีกชุด
- **เขียน component ของ PA ใหม่ตามแบบ Data Center:** หน้าตาตรงกันที่สุด แต่เป็นการสร้าง PA ใหม่ และแตะโค้ดที่คำนวณตัวเลข
- **เลิก freeze ทั้งหมด:** เปิดให้แก้พฤติกรรมและการคำนวณ ซึ่งไม่มีใครขอ

## ผลที่ตามมา

- ภาพของ `/pa` ไม่ตรงกับ production เดิมทุก pixel อีก การเทียบภาพของ SPEC §11 (ตรวจ 4 พ.ย. 2569) ใช้เป็นเกณฑ์ไม่ได้ เหลือ `pa:compare` ที่ตรวจตัวเลข
- `/sync` ใช้ token `brand-*` 6 จุดและ `slate-*` 13 จุด การเปลี่ยนค่า token ทั้งเว็บจึงเปลี่ยนสีของ `/sync` ด้วย ซึ่งยอมรับ: ค่าสีมีชุดเดียวทั้งเว็บ ไม่จำกัดไว้ใต้ `/pa` และไม่แก้ไฟล์ของ `/sync`
- Masthead เพิ่ม HTML และ CSS ให้ `/pa` ซึ่งเหลืองบ LCP 113 ms
- SPEC §11, CODING_STANDARDS §1 และ GLOSSARY "PA" แก้ตามแล้วใน F87

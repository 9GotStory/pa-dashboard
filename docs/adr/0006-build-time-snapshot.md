# ADR-0006: เว็บสาธารณะอ่านไฟล์ JSON ที่สร้างตอน build

- สถานะ: ยอมรับ · 29 ต.ค. 2569 (D7)
- เกี่ยวข้อง: SPEC §3, §6, SCHEMA §7

## บริบท

GAS ตอบช้า 1–3 วินาทีต่อคำขอ ทำงานพร้อมกันได้ราว 30 คำขอ และ `CacheService` เก็บได้ค่าละ 100 KB ถ้าเว็บสาธารณะเรียก GAS สดทุกครั้งที่เปิดหน้า เว็บจะช้าและล้มตาม GAS ทั้งที่ข้อมูลเปลี่ยนวันละครั้ง

## การตัดสินใจ

- prebuild script ดึง `catalog` และ `report` ทุกตัวจาก GAS มาเขียน `public/data/*.json` ตอน `npm run build` หน้า Data Center อ่านไฟล์เหล่านี้เท่านั้น ไม่เรียก GAS
- GAS สั่ง rebuild ผ่าน Cloudflare Deploy Hook หลัง sync (จำกัด 5 ครั้ง/วัน)
- build ล้มเมื่อข้อมูลไม่ครบ (GAS ตอบไม่ได้, จำนวนแถวไม่ตรง `sync_status`, ไฟล์ใหญ่เกิน) เพื่อไม่ publish ข้อมูลผิด Cloudflare คงเวอร์ชันก่อนหน้าไว้
- GAS ถือ script lock ตอนตอบ `catalog`/`report` กันการอ่านชีตที่กำลังถูกเขียน
- PA และ `/sync` ยังเรียก GAS สด (ADR-0003)

## ผลที่ตามมา

- หน้าเปิดได้ทันทีจาก CDN เว็บอยู่ได้แม้ GAS ล่ม URL ของ GAS ไม่อยู่ในหน้า Data Center
- ข้อมูลบนเว็บสดเท่ากับ build ล่าสุด การเปิดรายงานใหม่ในชีตต้องสั่ง rebuild
- รายงานกลายเป็น route จริง `/reports/{id}` เพราะรายการรู้ตอน build

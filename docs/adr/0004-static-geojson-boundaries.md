# ADR-0004: ขอบเขตตำบลเป็นไฟล์ GeoJSON คงที่

- สถานะ: ยอมรับ · 29 ต.ค. 2569 (D4)
- เกี่ยวข้อง: SPEC §9.2, SCHEMA §8

## บริบท

ต้นแบบ R6 ดึงขอบเขตตำบลสดจาก ArcGIS ของ MOPH/ปภ./GISTDA ผ่าน CORS และ JSONP ซึ่งต้นแบบเองก็ระบุว่าเป็นวิธีชั่วคราว

## การตัดสินใจ

ดาวน์โหลดขอบเขต 8 ตำบลของอำเภอสองครั้งเดียว เก็บเป็น `public/geo/song-tambon.geojson` (ใช้ `ADMIN_ID3` จับคู่กับ `tambon_master.id`) และบันทึกแหล่ง/วันที่ใน `public/geo/README.md`

## ผลที่ตามมา

- แผนที่ไม่พึ่งบริการภายนอกนอกจาก tiles ของ OpenStreetMap และยังใช้งานได้เมื่อ tiles โหลดไม่ได้
- ขอบเขตเปลี่ยนเมื่อมีคนดาวน์โหลดใหม่เท่านั้น ซึ่งเหมาะกับข้อมูลที่แทบไม่เปลี่ยน

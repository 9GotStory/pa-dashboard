# ADR-0008: แค็ตตาล็อกรายงานตามโครง HDC แบบ opt-in และกลุ่มกำหนดเอง

- สถานะ: ยอมรับ · 29 ต.ค. 2569
- เกี่ยวข้อง: SPEC §5, SCHEMA §2.2–2.3, §3.4, §5

## บริบท

HDC Open Data มี API แค็ตตาล็อกเป็น หมวด → หัวข้อ → รายงาน (51 หัวข้อ ราว 1,200 รายงาน มีรายการซ้ำและรายการขยะ) แต่ไม่มีชั้น "กลุ่ม" เช่น กลุ่มอายุ 1 ปี/2 ปี ที่ผู้ใช้ต้องการ และเราต้องการเฉพาะบางรายงาน

## การตัดสินใจ

- จัดรายงานตามโครงของ HDC ใช้ `cat_id` (= `subcatalogId`) และ `opendata_id` (= `id` ในข้อมูลดิบ) เป็น key
- เลือกเฉพาะที่ต้องการ 2 ชั้น: หัวข้อใน `hdc_topics` (เรียก API เฉพาะหัวข้อเหล่านี้) และรายงานใน `hdc_reports` ด้วย `enabled` ซึ่งรายงานใหม่เป็น FALSE เสมอ
- "กลุ่ม" และลำดับเป็นคอลัมน์ `subgroup`/`order` ที่ผู้ดูแลกรอก ใช้กฎเรียงเดียวกับ PA (`sortKpisByGroup`) บวกกลุ่มว่างอยู่ท้าย
- `source_table` ต้องขึ้นต้นด้วย `s_` เพราะชื่อนี้กลายเป็นชีตที่ `doPost` เขียนได้
- รีเฟรชแค็ตตาล็อกไม่แตะคอลัมน์ที่ผู้ดูแลกรอก และไม่ลบรายงานที่หายจาก API (ตั้ง `removed`)

## ผลที่ตามมา

- รายการขยะไม่ต้องจัดการ แค่ไม่เปิด
- ตารางเดียวมีหลายรายงานได้ (`s_epi_complete` 4 กลุ่มอายุ) จึงต้องกรอง `id` เสมอเมื่อชีตมีคอลัมน์นี้
- หลังแก้ชีตแค็ตตาล็อกต้องสั่ง rebuild (ADR-0006)

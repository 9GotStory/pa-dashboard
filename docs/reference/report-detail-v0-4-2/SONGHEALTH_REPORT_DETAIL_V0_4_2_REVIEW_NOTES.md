# SONGHEALTH — Report Detail V0.4.2 / Final Detail Polish

**วันที่:** 10 พฤศจิกายน 2569  
**งาน:** เก็บรายละเอียด UX/UI ของ EPI1 และ AGED9 ต่อจาก V0.4.1  
**สถานะ:** ต้นแบบให้ Product Owner ตรวจรับเท่านั้น; ไม่ได้แก้ไข GitHub Repository, SPEC, GAS, Google Sheets หรือ Production

## Design baseline (ไม่เปลี่ยน)

- ANC V0.2 คือมาตรฐานที่ผ่านการตรวจรับและคงไฟล์เดิมทุกประการ
- EPI1 ภาพรวมวัคซีน 20 รายการในตารางพร้อมแถบระดับ และเปิดรายละเอียดเฉพาะเมื่อเลือกวัคซีน
- AGED9 ความครอบคลุม KPI/กราฟ/ตาราง/แนวโน้ม ตามด้วยจำนวนคัดกรอง 9 ด้านที่เจาะลึกได้
- ส่วนหัวเว็บไซต์ เมนู Breadcrumb ชื่อรายงาน ตัวกรอง ปุ่ม CSV/พิมพ์ รายงานที่เกี่ยวข้อง และ Footer ยึดโครง ANC V0.2 ต่อเนื่อง

## สิ่งที่เก็บเพิ่ม V0.4.2

1. เพิ่มการกดเลือกรายการวัคซีนในตารางด้วยปุ่มจริง (semantic HTML): คีย์บอร์ด Enter/Space ใช้ได้ ไม่ใช้ `<tr role=button>` ที่กระทบความหมายตารางและอาจเกิดการเรียกซ้ำ
2. สถานะ `aria-expanded` และ `aria-controls` สำหรับรายการวัคซีนและด้านคัดกรอง รวมถึงเพิ่ม focus ring เฉพาะปุ่มที่ผู้ใช้กด
3. เมื่อค้นหาวัคซีน จะแสดงจำนวนที่พบจากทั้งหมด และแสดงสถานะไม่พบข้อมูลชัดเจน
4. แสดง `—` แทน `—%` เมื่อไม่มีตัวหาร/เป้าหมายในช่วงที่เลือก และไม่ตีความการไม่มีข้อมูลว่าไม่ผ่านเกณฑ์ใน AGED9
5. เพิ่ม context ของรายละเอียดด้านคัดกรอง (ปี / พื้นที่) และคำเตือนว่าเป็น **จำนวนรายการ** ไม่ใช่จำนวนผู้มีความเสี่ยง
6. ปรับกราฟแนวโน้มบน Mobile ให้แสดงปี + แถบ + ตัวเลขร้อยละที่อ่านได้ โดยกราฟเส้นบน Desktop คงเดิม
7. เอากรอบดำออกจากหัวข้อที่มีการย้าย keyboard focus แบบโปรแกรม หลังเปิดรายละเอียด; เมื่อปิดรายละเอียด โฟกัสกลับไปหัวข้อภาพรวม
8. เมนูมือถือปิดด้วย Escape ได้ โดยคืนโฟกัสที่ปุ่มเมนู
9. คง Footer, Breadcrumb, Filter และการนำเสนอ V0.4.1 เป็นหลัก; ไม่มีการเพิ่มกราฟหรือปุ่มแสดงผลส่วนเกิน

## การตรวจคุณภาพจริง

- Chromium headless 320, 390, 768, 1440, 1920 พิกเซล **10 กรณีผ่าน**: ไม่มี document overflow แนวนอน, ไม่มี page error
- คงเมนูนำทาง Desktop 5 รายการ, ตัวกรองหน้า EPI1/AGED9 อย่างละ 3 ช่อง
- Mobile: เมนูเปิด-ปิด รวม Escape ได้
- EPI1: ครบ 20 รายการ; ค้นหา MMR ได้ 1/20 และไม่พบข้อมูลได้ 0/20; เลือก MMR ผ่านคีย์บอร์ด; เปิด/ปิดรายละเอียดและตรวจโฟกัส; ตัวเลขรวม MMR ปี 2569 = 174
- EPI1: ตรวจช่วงที่เป้าหมายเป็นศูนย์แล้วไม่แสดง `—%`; เปลี่ยนปี/ตำบล/เดือนหรือไตรมาสแล้วค่าเปลี่ยนตาม
- AGED9: KPI ปี 2569 เป้าหมาย 12,188; แสดงครบ 9 ด้าน; เปิด/ปิดสุขภาพช่องปากผ่านคีย์บอร์ด; เปลี่ยนปี/ตำบลและปรับหน่วยเปรียบเทียบโดยอัตโนมัติ
- ทั้งสองหน้า: ดาวน์โหลด CSV มี UTF-8 BOM เหมาะกับ Excel, เปิดรายละเอียดบนมือถือได้, ไม่มี JS errors
- ภาพที่แนบ: Desktop/Mobile พร้อมภาพเปิดรายละเอียดสำหรับ EPI1/AGED9
